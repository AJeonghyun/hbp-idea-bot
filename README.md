# HBP 아이디어봇

매일 한국 시간 오전 9시와 오후 9시에 HBP의 `#아이디어`에 영상 질문 일곱 개와 각각의 첫 장면을 게시한다.

GitHub Actions가 한 시간 전에 주제를 준비해 Slack의 예약 전송에 등록한다. 실행이 밀리면 목표 시각 이후 90분 안에서 즉시 전송한다. 같은 회차를 다시 실행하면 앱의 예약 목록과 채널 게시 기록을 확인한다.

일상 질문은 직접 편집한 질문·첫 장면 목록과 비교 실험에서 최근 사용하지 않은 항목을 먼저 고른다. 연합뉴스 연예 RSS에서 조건에 맞는 기사가 있으면 최대 두 개를 원문 링크와 함께 소개한다. 추천 글과 채널 안내는 Slack Block Kit로 표시하며 알림과 스크린 리더에는 같은 내용의 대체 텍스트를 제공한다.

## 운영

- Actions의 **영상 아이디어 → Run workflow**에서 회차와 미리보기 여부를 고른다. 기본값은 미리보기다.
- 채널 ID는 워크플로에 지정되어 있고, 전용 봇 토큰은 저장소 Actions secret `SLACK_BOT_TOKEN`에서 관리한다. 봇은 대상 공개 채널의 멤버여야 한다.
- 질문과 첫 장면은 `catalog.mjs`에서 편집한다. Node.js 24에서 `node --test`로 검증하고 `IDEA_SLOT=09 node ideas.mjs --dry-run`으로 한 회차를 미리 본다.

## 팀 투표

추천 글에 원하는 번호의 이모지 반응(1️⃣~7️⃣)을 단다. 여러 주제에 투표할 수 있다. 추천 글의 각 번호 이모지 옆에서 현재 득표수를 확인한다. 투표는 마감 없이 열려 있고 제작 주제는 팀에서 직접 정한다.
